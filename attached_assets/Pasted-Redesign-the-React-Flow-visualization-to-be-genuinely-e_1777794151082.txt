--- ENRICHED NODE CONTENT ---

Each node must show 3 information layers:

TOP: Operation name in bold (e.g., "dropna()")
MIDDLE: Key parameters extracted from AST 
        (e.g., subset=["Age","Embarked"] — truncate to 30 chars)
BOTTOM: Impact badge — colored pill showing data shape delta:
  - Green pill: shape unchanged or rows added 
  - Orange pill: shape slightly reduced (<30% row loss)
  - Red pill: significant reduction (>30% row loss)
  - Blue pill: new columns added
  For PyTorch: show tensor shape (e.g., [32,128] → [32,64])

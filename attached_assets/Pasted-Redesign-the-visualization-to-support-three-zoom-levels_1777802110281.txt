--- LEVEL 1: ARCHITECTURE VIEW (default) ---

When code is first visualized, show the HIGH-LEVEL view:
One large block per class or top-level function.

Each block shows:
- Block type badge: CLASS / FUNCTION / MODULE
- Name (large, bold): e.g., "ConvNet", "train_loop", "ImageDataset"
- Summary line (small, muted): auto-generated from the code
  e.g., "3 layers · forward() · __init__()"
  e.g., "20 epochs · Adam optimizer · CrossEntropyLoss"
- Node count badge (bottom-right): "12 ops inside →"

Arrows between blocks represent:
- CALLS: function/class A calls or instantiates B
  → solid arrow, label "calls"
- PASSES DATA: A passes a variable to B  
  → dashed arrow, label with variable name (e.g., "train_loader")
- INHERITS: class A inherits from B (nn.Module)
  → dotted arrow with hollow arrowhead, label "extends"

Blocks are large (min 200×120px), colorful, and well-spaced.
Use the existing color system:
  Classes → blue (#3b82f6) with strong border
  Functions → purple (#8b5cf6)
  Data flows (DataLoader, DataFrame) → green (#22c55e)
  Loss/Optimizer → red (#ef4444)

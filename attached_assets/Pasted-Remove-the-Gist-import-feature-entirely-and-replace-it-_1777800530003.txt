--- BACKEND: /fetch-repo ENDPOINT ---

POST /fetch-repo
Request: { "url": "https://github.com/username/repo" }

STEP 1 — Get file list:
1. Extract owner + repo from URL with regex
   Handle: github.com/owner/repo, with or without https://, 
   with or without trailing slash
   
2. Fetch repo contents recursively (max 3 levels deep):
   GET https://api.github.com/repos/{owner}/{repo}/contents/{path}
   
3. Filter to .py files only
   Exclude: __pycache__/, venv/, .venv/, migrations/, 
            test_*.py, *_test.py, setup.py, conftest.py
   
4. Return sorted file list:
   [ { "name": "train.py", "path": "src/train.py", "size": 3200 } ]
   Sort: largest file first (most likely the main entry point)

5. Also check for a README to extract the repo description:
   GET https://api.github.com/repos/{owner}/{repo}
   Return: repo name, description, star count, language

POST /fetch-file  
Request: { "owner": "...", "repo": "...", "path": "..." }

1. GET https://api.github.com/repos/{owner}/{repo}/contents/{path}
2. base64 decode the "content" field
3. Return: { "code": "...", "filename": "..." }
